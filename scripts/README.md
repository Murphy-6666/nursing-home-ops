# 飞书 API 自动建表脚本

通过飞书 OpenAPI 一键创建养老院所需的 15 张多维表格，自动设置字段类型、选项、关联关系和公式字段。

## 前置条件

1. 注册 [飞书开放平台](https://open.feishu.cn/app) 应用，获取 `App ID` 和 `App Secret`
2. 给应用开通多维表格权限：`bitable:app`
3. 创建一个空的飞书多维表格，从 URL 中获取 `app_token`

## 四步搞定

```bash
# 1. 安装依赖
cd scripts
npm install

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 填入 APP_TOKEN、APP_ID、APP_SECRET

# 3. 一键建表
npm start

# 4. 写入演示数据（可选，建表后运行）
npm run seed

# 验证是否全部创建成功
npm run verify
```

## 验证脚本

```bash
npm run verify
```

会检查：
- 15 张表是否全部创建
- 每张表的字段是否齐全
- 输出通过/警告/失败的统计

## 文件说明

| 文件 | 说明 |
|------|------|
| `table-definitions.js` | 所有表和字段的定义（改这里就能自定义表结构） |
| `create-tables.js` | 建表主脚本 |
| `verify-setup.js` | 验证脚本 |
| `seed-demo-data.js` | 演示数据生成脚本（6名员工、5位老人、7天护理记录等） |
| `.env.example` | 环境变量模板 |
| `table-id-mapping.json` | 运行后生成，记录各表 ID |

## 常见问题

**Q: 公式字段创建失败怎么办？**
A: 飞书 API 对公式字段的支持有限，如果创建失败，请按 SETUP.md 中的公式列表手动添加。

**Q: 关联字段显示的不是我想要的列怎么办？**
A: 关联字段默认显示目标表的第一列。建表完成后在飞书中手动调整关联显示字段即可。

**Q: 想增减字段怎么办？**
A: 编辑 `table-definitions.js`，修改对应表的 fields 数组，重新运行 `npm start`。
