# 飞书 API 自动建表脚本

通过飞书 OpenAPI 一键创建养老院所需的 9 张多维表格，自动设置字段类型、选项和关联关系。

## 前置条件

1. 注册 [飞书开放平台](https://open.feishu.cn/app) 应用，获取 `App ID` 和 `App Secret`
2. 给应用开通多维表格权限：`bitable:app`（读写多维表格）
3. 创建一个空的飞书多维表格，从 URL 中获取 `app_token`
   - URL 格式：`https://xxx.feishu.cn/base/APP_TOKEN`，其中 `APP_TOKEN` 就是你需要的值

## 使用步骤

### 1. 安装依赖

```bash
cd scripts
npm install
```

### 2. 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env` 文件，填入你的 `APP_TOKEN`、`APP_ID`、`APP_SECRET`。

### 3. 运行脚本

```bash
npm start
```

脚本会自动：
1. 获取飞书访问令牌
2. 按顺序创建 9 张数据表（先建基础表，再建关联表）
3. 为每张表创建所有字段，自动设置类型和选项
4. 配置表间关联关系
5. 输出 `table-id-mapping.json` 保存各表 ID

## 创建的表格

| 表名 | 字段数 | 关联表 |
|------|--------|--------|
| 老人基本信息表 | 17 | - |
| 护理记录表 | 19 | 老人基本信息表、员工表 |
| 用药方案表 | 13 | 老人基本信息表 |
| 排班表 | 8 | 员工表 |
| 健康数据表 | 12 | 老人基本信息表、员工表 |
| 费用台账表 | 10 | 老人基本信息表 |
| 活动记录表 | 13 | 员工表 |
| 员工表 | 7 | - |
| 家属联系表 | 6 | 老人基本信息表 |

## 注意事项

- 公式字段（如「异常标记」「异常等级」「年龄」）需在脚本运行后手动添加，飞书 API 暂不支持直接创建公式字段
- 关联字段会自动指向正确的表，但关联的显示字段默认为该表的第一列
- 脚本运行后会在 `scripts/` 目录下生成 `table-id-mapping.json`，记录各表的 `table_id`，后续 API 调用会用到
