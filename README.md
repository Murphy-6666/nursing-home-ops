# 养老院日常运营 AI 工作流

> 基于 AI + 飞书生态的养老院数字化运营解决方案，覆盖护理记录、家属沟通、排班、用药、健康监测、餐饮、活动、财务八大场景。

## 为什么需要这个项目

养老院日常运营面临三大痛点：

- **纸质记录效率低**：护理员每天花大量时间手写记录，还容易遗漏
- **家属沟通成本高**：家属频繁打电话询问情况，护理员疲于应对
- **管理数据散乱**：排班、用药、健康数据分散在不同表格，无法统一分析

本项目通过 AI + 飞书生态，将这些流程数字化、自动化，让护理员专注于照护本身。

## 快速开始

### 前置条件

- 飞书企业版账号（或飞书个人版）
- TRAE AI 助手（用于运行 skill）

### 安装

1. 将 `SKILL.md` 复制到 `.trae/skills/nursing-home-ops/SKILL.md`
2. 在 TRAE 中对 AI 说：「帮我搭建养老院的多维表格基础架构」
3. AI 会根据 skill 中的指引，逐步帮你完成搭建

### 推进路线

| 阶段 | 时间 | 内容 |
|------|------|------|
| 第一周 | 基础搭建 | 老人档案 + 护理记录 + 排班表 |
| 第二周 | 核心流程 | 语音转文字 + 家属自动推送 |
| 第三周 | 安全保障 | 用药提醒 + 健康预警 |
| 第四周 | 运营优化 | 餐饮 + 活动 + 财务报表 |

## 功能模块

### 马上能做（无需额外设备）

| 模块 | 核心能力 | 价值 |
|------|---------|------|
| 护理记录自动化 | 语音录入 → AI提取 → 自动归档 | 效率翻倍，杜绝漏记 |
| 家属沟通自动化 | 每日摘要 + 每周周报自动推送 | 减少电话打扰，家属安心 |
| 排班管理 | 智能排班 + 冲突检测 + 日历同步 | 排班公平，避免冲突 |
| 用药提醒 | 定时推送 + 确认跟踪 | 杜绝漏服错服 |

### 配置后可用

| 模块 | 核心能力 | 价值 |
|------|---------|------|
| 健康档案与预警 | 体征数据录入 + 异常自动标红 | 提前干预，降低风险 |
| 餐饮管理 | 禁忌管理 + AI营养配餐 | 减少出错，营养均衡 |
| 活动管理 | AI方案生成 + 效果追踪 | 活动丰富，数据驱动 |
| 财务管理 | 自动账单 + 收支报表 | 账目清晰，对账省心 |

## 技术栈

- **AI 引擎**：TRAE AI（语音转文字、自然语言处理、内容生成）
- **数据层**：飞书多维表格（Bitable）
- **协作层**：飞书IM、飞书文档、飞书日历
- **自动化**：飞书多维表格自动化 + AI定时任务

## 适用对象

- 养老院、养护院、老年公寓
- 社区养老服务中心
- 居家养老服务平台
- 康养中心、护理院
