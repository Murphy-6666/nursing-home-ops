# 飞书多维表格字段定义

本文件定义养老院运营所需的 15 张多维表格的字段结构。

> CSV 模板见 `templates/csv/` 目录，可直接导入飞书多维表格。

---

## 基础表（先建）

### 1. 老人基本信息表

| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|---------|---------|------|
| 姓名 | 文本 | 是 | - |
| 性别 | 单选 | 是 | 男/女 |
| 出生年月 | 日期 | 是 | - |
| 年龄 | 公式 | - | `DATEDIF(出生年月, TODAY(), "Y")` |
| 入住日期 | 日期 | 是 | - |
| 房间号 | 文本 | 是 | 如：A-301 |
| 床位号 | 文本 | 是 | 如：1 |
| 护理等级 | 单选 | 是 | 自理/半护理/全护理/特护 |
| 饮食类型 | 单选 | 是 | 普食/软食/半流食/流食 |
| 饮食禁忌 | 多选 | 否 | 糖尿病饮食/低盐/低脂/低嘌呤/无麸质 |
| 过敏食物 | 多选 | 否 | 海鲜/鸡蛋/牛奶/坚果/其他 |
| 主要疾病 | 文本 | 否 | 如：高血压、糖尿病 |
| 紧急联系人 | 文本 | 是 | 姓名+关系+电话 |
| 家属飞书ID | 文本 | 否 | 用于推送消息 |
| 上次体检日期 | 日期 | 否 | - |
| 体检报告 | 附件 | 否 | 飞书云空间链接 |
| 状态 | 单选 | 是 | 在住/出院/请假 |
| 备注 | 文本 | 否 | - |

| 字段名 | 字段类型 | 是否必填 | 说明 |
