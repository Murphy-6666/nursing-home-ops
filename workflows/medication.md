# 用药提醒

## 场景描述

养老院老人通常需要按时服用多种药物，漏服、错服、重复服药都是重大安全隐患。

## 痛点

- 老人用药方案复杂（降压药、降糖药、心脏病药等，时间各不相同）
- 依靠护理员记忆容易遗漏
- 服药记录不完整，无法追溯
- 药品库存管理混乱

## 解决方案

多维表格管理用药方案 → 飞书日历定时提醒 → 服药确认跟踪 → 库存预警。

## 实施步骤

### 第1步：创建用药方案表

字段定义见 [templates/base-schema.md](../templates/base-schema.md) 的用药方案表部分。

核心字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 老人姓名 | 关联 | 关联老人基本信息表 |
| 药品名称 | 文本 | 如：氨氯地平片 |
| 剂量 | 文本 | 如：5mg/1片 |
| 服药时间 | 文本 | 如：每日08:00 |
| 服药方式 | 单选 | 餐前/餐后/睡前/空腹 |
| 开始日期 | 日期 | - |
| 结束日期 | 日期 | 长期用药则留空 |
| 状态 | 单选 | 服用中 / 已停药 / 已完成 |
| 备注 | 文本 | 如：需配合温水送服 |

### 第2步：创建服药记录表

| 字段 | 类型 | 说明 |
|------|------|------|
| 日期 | 日期 | - |
| 老人姓名 | 关联 | - |
| 药品名称 | 文本 | - |
| 应服时间 | 文本 | - |
| 实际服药时间 | 文本 | - |
| 服药状态 | 单选 | 已服 / 拒绝 / 漏服 |
| 操作人 | 关联 | 护理员 |
| 备注 | 文本 | - |

### 第3步：配置定时提醒

```
方式1：飞书日历定时事件
  → 每个用药方案创建一个重复日历事件
  → 事件标题：「用药提醒 - 张奶奶 - 氨氯地平片 1片」
  → 到点提醒当班护理员

方式2：AI 定时任务
  → 每天根据用药方案表生成当日用药清单
  → 按时间排序，推送给当班护理员
  → 护理员逐项确认

方式3：多维表格自动化
  → 到点触发飞书IM消息
  → 消息卡片含「已服」/「拒绝」/「稍后」按钮
  → 点击即记录服药状态
```

### 第4步：漏服预警

```
触发条件：应服时间 +30分钟 仍未确认
  → 推送加急消息给当班主管
  → 消息内容：「张奶奶 08:00 氨氯地平片 尚未确认服药」

触发条件：当天用药清单中有漏服记录
  → 20:00 汇总漏服情况
  → 推送给主管
```

### 第5步：药品库存管理

在多维表格中增加「药品库存表」：

| 字段 | 类型 | 说明 |
|------|------|------|
| 药品名称 | 文本 | - |
| 当前库存 | 数字 | 盒数 |
| 单盒用量 | 数字 | 如：30片/盒 |
| 预警阈值 | 数字 | 如：5盒 |
| 预计耗尽日期 | 公式 | 库存/日均消耗 |
| 状态 | 公式 | 充足 / 偏低 / 预警 |

```
触发条件：库存 < 预警阈值
  → 推送采购提醒给药房/采购员
  → 附带预计耗尽日期
```

## 自动化规则

```
触发条件：每天 07:00
  → 从用药方案表生成当日用药清单
  → 按时间排序推送给当班护理员

触发条件：每个用药时间点
  → 推送服药提醒消息卡片给当班护理员
  → 护理员点击确认/拒绝/稍后
  → 记录入服药记录表

触发条件：应服时间 +30分钟 未确认
  → 推送加急消息给主管

触发条件：每天 20:00
  → 汇总当日用药情况
  → 统计服药率、漏服次数
  → 推送给主管
```

## 效果指标

| 指标 | 改造前 | 改造后 |
|------|--------|----------|
| 漏服率 | 约8% | <1% |
| 服药记录完整度 | 约60% | 100% |
| 用药清单生成 | 手动整理15分钟 | 自动生成0分钟 |
| 药品断供风险 | 偶有发生 | 提前预警 |
