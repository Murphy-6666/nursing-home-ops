# 活动管理

## 场景描述

养老院需要定期组织文娱活动（手指操、唱歌、手工、怀旧疗法等），丰富老人精神生活，延缓认知衰退。

## 痛点

- 活动方案靠经验，缺乏针对性
- 参与情况靠人工清点，数据不准
- 活动效果无法量化评估
- 活动安排与老人能力不匹配

## 解决方案

AI生成活动方案 + 参与记录数字化 + 效果评估 + 个性化推荐。

## 实施步骤

### 第1步：创建活动库

在多维表格中创建「活动方案表」：

| 字段 | 类型 | 说明 |
|------|------|------|
| 活动名称 | 文本 | 如：手指保健操 |
| 活动类型 | 单选 | 运动 / 音乐 / 手工 / 认知 / 社交 / 节日 |
| 适合能力等级 | 多选 | 自理 / 半护理 / 全护理 / 认知障碍 |
| 时长(分钟) | 数字 | - |
| 所需物资 | 文本 | - |
| 所需人手 | 数字 | - |
| 活动描述 | 文本 | 详细步骤 |
| 难度等级 | 单选 | 简单 / 中等 / 较难 |

### 第2步：AI 生成每周活动计划

```
输入：
  - 院内老人能力等级分布
  - 上周活动安排（避免重复）
  - 天气情况（室内/室外）
  - 节日/纪念日
  - 可用人手

AI 生成：
  1. 每周活动排期表（每天1-2场活动）
  2. 每场活动的详细方案（步骤、物资、注意事项）
  3. 适合参与的老名单（按能力等级匹配）
  4. 特殊关注老人（如：认知障碍老人需一对一陪同）
```

### 第3步：创建活动记录表

| 字段 | 类型 | 说明 |
|------|------|------|
| 活动日期 | 日期 | - |
| 活动名称 | 关联 | 关联活动方案表 |
| 开始时间 | 文本 | - |
| 结束时间 | 文本 | - |
| 应参加人数 | 数字 | - |
| 实参加人数 | 数字 | - |
| 参与老人 | 多选关联 | - |
| 参与度 | 单选 | 高 / 中 / 低 |
| 老人反馈 | 单选 | 积极 / 中性 / 消极 |
| 活动照片 | 附件 | - |
| 带领人 | 关联 | - |
| 备注 | 文本 | - |

### 第4步：效果评估

```
每周汇总指标：
  - 活动举办场次
  - 平均参与率（实参加/应参加）
  - 活动类型分布（运动/音乐/手工等占比）
  - 最受欢迎活动 TOP3
  - 参与度最低活动
  - 个性化趋势：每位老人的参与频次变化

每月评估：
  - 活动多样性评分
  - 老人参与度趋势
  - 活动与健康指标的关联分析
  - AI 建议优化方向
```

### 第5步：个性化推荐

```
基于每位老人的：
  - 能力等级
  - 历史参与记录
  - 反馈偏好
  - 健康状况

AI 推荐：
  - 适合该老人的活动类型
  - 建议参与的频次
  - 需要特别邀请的老人（近期参与度下降）
  - 需要调整难度的老人
```

## 自动化规则

```
触发条件：每周日 18:00
  → AI 生成本周活动排期草稿
  → 推送给活动主管确认
  → 确认后同步到飞书日历

触发条件：活动结束后
  → 护理员填写活动记录
  → AI 分析参与度数据
  → 异常（参与率<50%）推送提醒

触发条件：每月1日
  → 生成上月活动效果评估报告
  → AI 建议下月活动优化方向
```

## 活动方案示例

### 手指保健操（简单级别）

```
时长：20分钟
适合：自理 / 半护理
物资：无
人手：1人带领

步骤：
1. 热身（3分钟）：搓手、转腕
2. 基础动作（10分钟）：
   - 逐指弯曲伸展
   - 拇指对四指触碰
   - 手指张合练习
   - 抓握练习（可握软球）
3. 放松（3分钟）：轻柔按摩手掌
4. 互动（4分钟）：手指游戏/歌谣配合

注意：
- 全护理老人可由护理员辅助进行被动手指活动
- 过程中观察老人反应，如有不适立即停止
```

## 效果指标

| 指标 | 改造前 | 改造后 |
|------|--------|----------|
| 活动规划耗时 | 1-2小时/周 | 20分钟/周 |
| 参与率 | 约50% | >75% |
| 活动多样性 | 重复率高 | 类型均衡 |
| 效果评估 | 无法量化 | 数据驱动 |
