# 家属沟通自动化

## 场景描述

家属经常打电话询问老人的饮食、睡眠、用药、精神状态等情况，护理员需要反复回答相同问题，占用大量时间。

## 痛点

- 家属平均每天打 1-3 个电话询问情况
- 高峰期（晚间）电话集中，护理员忙不过来
- 口头沟通信息不完整，家属容易遗漏
- 家属焦虑感强，缺乏规律性信息输入

## 解决方案

每日自动推送护理摘要 + 每周自动生成结构化周报，通过飞书IM发送给家属。

## 实施步骤

### 第1步：建立家属通讯录

在多维表格中创建「家属联系表」：

| 字段 | 类型 | 说明 |
|------|------|------|
| 家属姓名 | 文本 | - |
| 关系 | 单选 | 子女/配偶/其他 |
| 联系方式 | 文本 | 手机号或飞书ID |
| 对应老人 | 关联 | 关联老人基本信息表 |
| 推送频率 | 单选 | 每日/每周/不推送 |
| 推送时间 | 文本 | 如 20:00 |

### 第2步：配置每日摘要推送

每天 20:00 自动从护理记录表中提取每位老人当天的数据，生成摘要：

```
【今日护理摘要 - 张奶奶】
日期：2024-01-15

饮食：早餐吃了大半碗粥+鸡蛋，午餐半碗饭+蔬菜，晚餐正常
用药：早8点降压药1片（已确认服用）
体征：血压 135/85，体温 36.5℃，均在正常范围
精神：精神状态良好，下午参加了手指操活动
睡眠：午睡约1小时
备注：无特殊情况
```

### 第3步：配置每周周报

每周日 18:00 自动生成本周周报，使用 [templates/weekly-report.md](../templates/weekly-report.md) 模板：

```
【本周状态周报 - 张奶奶】
周期：2024-01-08 至 2024-01-14

一、饮食情况
- 本周食欲整体良好，日均进餐量稳定
- 周三午餐食量偏少，已关注

二、用药情况
- 本周用药7天全部按时服用
- 降压药每日1片，血压控制平稳

三、体征趋势
- 血压：平均 132/83，范围正常
- 体温：平均 36.4℃，无发热
- 体重：本周无变化

四、活动参与
- 参加活动5次（手指操3次、唱歌1次、手工1次）
- 参与积极性较高

五、下周关注
- 继续监测血压趋势
- 关注周三食量偏少情况
```

### 第4步：配置推送渠道

通过飞书IM发送给家属：

1. 个人飞书账号 → 直接发送消息
2. 建立家属群 → 每位老人一个家属群 → 群内推送
3. 无飞书家属 → 生成PDF → 飞书短信通知

## 自动化规则

```
触发条件：每天 20:00
  → 从护理记录表提取当日数据
  → AI 生成「今日护理摘要」
  → 按「家属联系表」中的推送频率发送
  → 记录推送状态

触发条件：每周日 18:00
  → 从护理记录表提取本周数据
  → AI 生成「本周状态周报」
  → 按「家属联系表」中的推送频率发送
  → 存档到飞书文档

触发条件：异常预警触发时
  → 立即推送异常通知给家属（可选）
  → 附带建议措施
```

## 效果指标

| 指标 | 改造前 | 改造后 |
|------|--------|----------|
| 家属日均来电 | 1-3次/家属 | <0.5次/家属 |
| 信息完整度 | 口头传达，易遗漏 | 结构化文档，可回看 |
| 护理员沟通耗时 | 约2小时/天 | <15分钟/天 |
| 家属满意度 | 焦虑、不确定 | 安心、可预期 |
