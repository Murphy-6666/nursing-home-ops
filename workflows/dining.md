# 餐饮管理

## 场景描述

养老院餐饮需要兼顾营养均衡、饮食禁忌（糖尿病、高血压、流食等）和老人口味偏好，传统方式靠厨师经验，容易出错。

## 痛点

- 饮食禁忌靠记忆，偶有出错
- 菜单重复率高，老人吃腻
- 营养搭配靠经验，缺乏科学依据
- 食材采购与菜单脱节，浪费或短缺

## 解决方案

多维表格管理禁忌 + AI生成营养菜单 + 食材采购清单 + 餐饮反馈跟踪。

## 实施步骤

### 第1步：创建饮食档案

在老人基本信息表中增加饮食相关字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 饮食类型 | 单选 | 普食 / 软食 / 半流食 / 流食 |
| 禁忌类别 | 多选 | 糖尿病饮食 / 低盐 / 低脂 / 低嘌呤 / 无麸质 |
| 过敏食物 | 多选 | 海鲜 / 鸡蛋 / 牛奶 / 坚果 / 其他 |
| 口味偏好 | 多选 | 偏甜 / 偏咸 / 偏辣 / 清淡 |
| 特殊备注 | 文本 | 如：只吃碎食、需要增稠剂 |

### 第2步：创建菜单表

| 字段 | 类型 | 说明 |
|------|------|------|
| 日期 | 日期 | - |
| 餐次 | 单选 | 早餐 / 午餐 / 晚餐 / 加餐 |
| 菜品名称 | 文本 | - |
| 食材清单 | 文本 | - |
| 营养标签 | 多选 | 低盐 / 低糖 / 低脂 / 高蛋白 / 高纤维 |
| 适合饮食类型 | 多选 | 普食 / 软食 / 半流食 / 流食 |
| 热量(千卡) | 数字 | - |
| 备注 | 文本 | - |

### 第3步：AI 菜单生成

```
输入：
  - 老人总数及饮食类型分布
  - 饮食禁忌统计
  - 过敏食物清单
  - 上周菜单（避免重复）
  - 季节食材

AI 生成：
  1. 每周7天 x 4餐次 = 28套菜单
  2. 每套菜单包含：主食 + 蛋白质 + 蔬菜 + 汤 + 加餐
  3. 自动标注每道菜的适合人群
  4. 确保禁忌老人有替代菜品
  5. 计算每日总热量，确保营养均衡
```

### 第4步：食材采购清单

```
触发条件：菜单确认后
  → AI 根据菜单 + 用餐人数计算食材用量
  → 生成采购清单（按食材分类）
  → 对比上周库存，计算实际采购量
  → 推送给采购员
```

采购清单格式：

```
【本周食材采购清单】
周期：2024-01-15 至 2024-01-21
用餐人数：30人

一、主食类
- 大米：50kg
- 面粉：20kg
- 杂粮：10kg

二、蛋白质类
- 鸡蛋：210个（30人 x 7天 x 1个）
- 鸡肉：15kg
- 鱼：10kg
- 豆腐：20kg

三、蔬菜类
- 时令蔬菜A：20kg
- 时令蔬菜B：15kg
...

四、特殊食材
- 糖尿病专用主食：5kg（5人 x 7天）
- 流食材料：增稠剂、米粉等
```

### 第5步：餐饮反馈跟踪

创建「餐饮反馈表」：

| 字段 | 类型 | 说明 |
|------|------|------|
| 日期 | 日期 | - |
| 餐次 | 单选 | - |
| 菜品名称 | 文本 | - |
| 进食量 | 单选 | 全部吃完 / 大半 / 一半 / 少量 / 拒食 |
| 反馈 | 单选 | 喜欢 / 一般 / 不喜欢 |
| 记录人 | 关联 | 护理员 |

```
触发条件：每周日 20:00
  → 汇总本周餐饮反馈
  → 统计：受欢迎菜品 TOP5、不受欢迎菜品 TOP5
  → 推送给厨师长
  → AI 建议下周菜单调整方向
```

## 自动化规则

```
触发条件：每周四 10:00
  → AI 生成本周菜单草稿
  → 推送给厨师长确认

触发条件：菜单确认后
  → 自动生成食材采购清单
  → 推送给采购员

触发条件：每天 20:00
  → 汇总当日餐饮反馈
  → 异常（拒食率高）立即提醒

触发条件：每周日 20:00
  → 生成本周餐饮反馈报告
  → AI 建议菜单优化方向
```

## 效果指标

| 指标 | 改造前 | 改造后 |
|------|--------|----------|
| 菜单规划耗时 | 2小时/周 | 20分钟/周 |
| 饮食禁忌出错 | 偶有发生 | 0次 |
| 菜品重复率 | 较高 | 显著降低 |
| 食材浪费率 | 约15% | <5% |
| 老人满意度 | 一般 | 提升 |
