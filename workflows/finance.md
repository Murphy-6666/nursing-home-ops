# 财务管理

## 场景描述

养老院费用项目多（床位费、护理费、餐费、医疗费、额外服务等），月底对账耗时，账单发送靠人工，容易出错。

## 痛点

- 费用项目多，手动计算容易漏项
- 月底集中开账单，工作量大
- 费用变更（如护理等级调整）追溯困难
- 收支报表手动制作，数据滞后

## 解决方案

多维表格费用台账 + 自动计算月账单 + 飞书推送账单 + 收支报表自动生成。

## 实施步骤

### 第1步：创建费用台账表

字段定义见 [templates/base-schema.md](../templates/base-schema.md) 的费用台账表部分。

核心字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 记账日期 | 日期 | - |
| 老人姓名 | 关联 | - |
| 费用类别 | 单选 | 床位费 / 护理费 / 餐费 / 医疗费 / 额外服务 |
| 费用明细 | 文本 | 如：特级护理 |
| 金额 | 数字 | 元 |
| 计费周期 | 单选 | 月结 / 日结 / 次结 |
| 状态 | 单选 | 未结算 / 已结算 / 已开票 |
| 备注 | 文本 | - |

### 第2步：创建收费标准表

| 字段 | 类型 | 说明 |
|------|------|------|
| 费用类别 | 单选 | - |
| 费用明细 | 文本 | - |
| 护理等级 | 单选 | 自理 / 半护理 / 全护理 / 特护 |
| 月收费标准 | 数字 | 元/月 |
| 日收费标准 | 数字 | 元/日 |
| 生效日期 | 日期 | - |
| 失效日期 | 日期 | - |

### 第3步：自动生成月账单

```
触发条件：每月1日 08:00
  → 从费用台账表提取上月所有费用记录
  → 按老人分组汇总
  → 匹配收费标准表验证金额
  → 生成每位老人的月度账单

账单格式：
  【张奶奶 - 2024年1月费用账单】
  
  一、常规费用
  - 床位费（双人间）：2,000元
  - 护理费（半护理）：3,500元
  - 餐费（普食）：1,500元
  
  二、额外费用
  - 1月10日 陪同就医：200元
  - 1月15日 理发服务：30元
  
  三、合计：7,230元
  
  四、上月余额：320元
  五、本月应付：6,910元
```

### 第4步：账单推送与确认

```
触发条件：月账单生成后
  → 通过飞书IM发送账单给家属
  → 消息卡片含「确认」/「有疑问」按钮
  → 点击「确认」→ 状态更新为「已确认」
  → 点击「有疑问」→ 推送给财务跟进

无飞书家属：
  → 生成PDF账单
  → 通过飞书短信通知
```

### 第5步：收支报表

多维表格仪表盘配置：

```
图表1：月度收入构成（饼图：床位费/护理费/餐费/其他）
图表2：月度收入趋势（折线图：近12个月）
图表3：入住率与收入关联（柱状图+折线图）
图表4：欠费统计（按老人、按金额排序）
图表5：额外服务收入占比
```

```
触发条件：每月1日
  → 生成上月收支报表
  → 推送给院长

触发条件：每周一 08:00
  → 生成上周费用台账周报
  → 统计新增费用、已结算、未结算金额
  → 推送给财务
```

### 第6步：欠费管理

```
触发条件：账单确认后7天未支付
  → 推送提醒给家属
  → 推送提醒给院长

触发条件：欠费超过30天
  → 推送加急通知给院长
  → 生成欠费清单
```

## 自动化规则

```
触发条件：每日记录新增费用
  → 自动匹配收费标准验证金额
  → 如金额异常 → 推送提醒给财务

触发条件：每月1日 08:00
  → 自动生成所有老人的月账单
  → 推送给家属确认
  → 生成月度收支报表推送给院长

触发条件：账单发送后7天/14天/30天
  → 分级催收提醒

触发条件：护理等级变更
  → 自动更新收费标准
  → 记录变更历史
  → 下月账单按新标准计算
```

## 效果指标

| 指标 | 改造前 | 改造后 |
|------|--------|----------|
| 月账单生成 | 2-3天 | 自动生成 |
| 账单出错率 | 约5% | <0.5% |
| 账单送达时效 | 月中才能发 | 月初即发 |
| 收支报表 | 月底手动制作 | 自动生成 |
| 欠费跟踪 | 靠记忆 | 自动提醒 |
