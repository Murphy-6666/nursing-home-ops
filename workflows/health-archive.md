# 健康档案与预警

## 场景描述

老人的体征数据（血压、血糖、体温、体重等）需要长期跟踪，趋势变化比单次数值更能反映健康状况。

## 痛点

- 体征数据记录在纸上，无法做趋势分析
- 异常发现滞后，错过最佳干预窗口
- 体检报告与日常记录脱节
- 医生查房时无法快速调阅历史数据

## 解决方案

多维表格健康数据表 + 趋势可视化 + 异常自动预警 + 体检报告归档。

## 实施步骤

### 第1步：创建健康数据表

字段定义见 [templates/base-schema.md](../templates/base-schema.md) 的健康数据表部分。

核心字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 记录日期 | 日期 | - |
| 老人姓名 | 关联 | - |
| 体温 | 数字 | ℃ |
| 收缩压 | 数字 | mmHg |
| 舒张压 | 数字 | mmHg |
| 心率 | 数字 | 次/分 |
| 血糖 | 数字 | mmol/L |
| 体重 | 数字 | kg |
| 记录人 | 关联 | 护理员 |
| 异常标记 | 公式 | 自动计算 |

### 第2步：设置异常判定规则

多维表格公式字段自动标记：

| 指标 | 正常范围 | 偏高 | 偏低 | 危险 |
|------|---------|------|------|------|
| 体温 | 36.0-37.3 | 37.4-38.0 | 35.5-35.9 | >38.0 或 <35.5 |
| 收缩压 | 90-140 | 141-160 | 80-89 | >160 或 <80 |
| 舒张压 | 60-90 | 91-100 | 50-59 | >100 或 <50 |
| 心率 | 60-100 | 101-120 | 40-59 | >120 或 <40 |
| 血糖(空腹) | 3.9-6.1 | 6.2-7.0 | 2.8-3.8 | >7.0 或 <2.8 |
| 血糖(餐后) | 3.9-7.8 | 7.9-11.0 | 2.8-3.8 | >11.0 或 <2.8 |

### 第3步：趋势可视化

多维表格仪表盘配置：

```
图表1：血压趋势折线图（近30天收缩压/舒张压）
图表2：血糖趋势折线图（近30天空腹/餐后）
图表3：体温趋势折线图（近30天）
图表4：体重变化柱状图（近3个月）
图表5：异常事件统计（按老人、按指标分类）
```

### 第4步：异常预警推送

```
触发条件：健康数据表新增记录，且异常标记为「危险」
  → 立即推送飞书IM消息给主管 + 当班医生
  → 消息内容包含：老人姓名、异常指标、具体数值、历史趋势
  → 建议：「建议立即复测并评估是否需要就医」

触发条件：异常标记为「偏高/偏低」
  → 推送消息给当班护理员
  → 建议：「请关注并增加监测频次」

触发条件：同一指标连续3天偏高/偏低
  → 推送汇总提醒给主管
  → 建议：「建议安排医生评估」
```

### 第5步：体检报告管理

```
老人基本信息表中增加字段：
  - 上次体检日期
  - 体检报告附件（飞书云空间链接）
  - 体检结论摘要

流程：
  1. 体检报告PDF上传到飞书云空间
  2. AI 提取关键指标和结论
  3. 与日常监测数据比对
  4. 生成「健康评估报告」
```

## 自动化规则

```
触发条件：健康数据表新增记录
  → 公式字段计算异常等级
  → 按等级推送预警消息
  → 更新趋势图表

触发条件：每周一 08:00
  → 生成本周健康监测重点提醒
  → 列出需要重点关注的老人和指标

触发条件：每月1日
  → 生成上月健康数据月报
  → 统计各指标的平均值、异常次数、趋势方向
```
