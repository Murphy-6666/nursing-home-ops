# 护理记录自动化

## 场景描述

护理员每天需要记录每位老人的护理情况（体征、用药、饮食、精神状态等），传统手写方式耗时且易遗漏。

## 痛点

- 手写记录平均每老人 5-8 分钟，30 个老人就是 2.5-4 小时
- 记录格式不统一，后期查阅困难
- 容易漏记（尤其夜班疲劳时）
- 纸质记录无法快速检索和统计

## 解决方案

语音录入 → AI 提取关键信息 → 自动归档到多维表格 → 异常值标红预警

## 实施步骤

### 第1步：创建护理记录表

在飞书多维表格中创建「护理记录表」，字段见 [templates/base-schema.md](../templates/base-schema.md) 的护理记录表部分。

### 第2步：配置语音录入流程

护理员通过以下方式录入：

```
方式1：飞书妙记录音 → AI转文字 → 提取信息入库
方式2：直接对TRAE AI说：「记录张奶奶今天血压135/85，吃了降压药」
方式3：飞书表单填写（适合不方便语音的场景）
```

### 第3步：AI 信息提取逻辑

AI 从语音/文字中提取以下字段：

| 提取项 | 示例 | 存入字段 |
|--------|------|----------|
| 老人姓名 | 张奶奶 | 老人姓名（关联老人基本信息表） |
| 记录日期 | 2024-01-15 | 记录日期 |
| 记录时间 | 08:30 | 记录时间 |
| 体温 | 36.5 | 体温 |
| 收缩压 | 135 | 收缩压 |
| 舒张压 | 85 | 舒张压 |
| 血糖 | 5.8 | 血糖 |
| 用药情况 | 吃了降压药 | 用药情况 |
| 饮食情况 | 半碗饭 | 饮食情况 |
| 精神状态 | 精神不错 | 精神状态 |
| 特殊备注 | 无 | 备注 |

### 第4步：异常值自动预警

多维表格设置条件格式：

| 指标 | 正常范围 | 预警颜色 |
|------|---------|----------|
| 体温 | 36.0-37.3℃ | 红色（超出范围） |
| 收缩压 | 90-140 | 橙色（偏高/偏低） |
| 舒张压 | 60-90 | 橙色（偏高/偏低） |
| 血糖（空腹） | 3.9-6.1 | 红色（超出范围） |
| 血糖（餐后） | 3.9-7.8 | 红色（超出范围） |

异常值触发飞书IM消息推送给当班主管。

### 第5步：日终汇总

每天 20:00 自动汇总当日所有护理记录，生成「当日护理摘要」，供家属推送使用（详见 family-notify.md）。

## 自动化规则

```
触发条件：护理记录表中新增记录
  → AI 检查体征数据是否超出正常范围
  → 如有异常 → 推送消息给主管
  → 如无异常 → 静默入库

触发条件：每天 20:00
  → 汇总当日所有护理记录
  → 生成「当日护理摘要」文档
  → 存入飞书文档「护理日志」文件夹
```

## 效果指标

| 指标 | 改造前 | 改造后 |
|------|--------|--------|
| 单人记录耗时 | 5-8分钟 | 1-2分钟 |
| 漏记率 | 约15% | <2% |
| 检索历史记录 | 翻本子10分钟 | 搜索3秒 |
| 异常发现延迟 | 数小时 | 实时 |
