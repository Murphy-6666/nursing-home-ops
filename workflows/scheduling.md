# 排班管理

## 场景描述

养老院需要 24 小时轮班，排班涉及白班/夜班/中班交替，还需考虑护理员技能搭配、连续夜班限制、请假调班等因素。

## 痛点

- 手动排班容易冲突（同一人同时排两个班）
- 夜班分配不均，引发护理员不满
- 临时调班混乱，信息不同步
- 无法快速查看谁在岗

## 解决方案

飞书多维表格排班 + 规则校验 + 飞书日历同步 + 临时调班审批流。

## 实施步骤

### 第1步：创建排班表

字段定义见 [templates/base-schema.md](../templates/base-schema.md) 的排班表部分。

核心字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 日期 | 日期 | - |
| 班次 | 单选 | 白班(08:00-16:00) / 中班(16:00-24:00) / 夜班(00:00-08:00) |
| 护理员 | 关联 | 关联员工表 |
| 负责区域 | 单选 | A区 / B区 / C区 |
| 状态 | 单选 | 正常 / 请假 / 调班 / 空缺 |

### 第2步：设置排班规则

多维表格公式字段自动校验：

```
规则1：同一人同一天不能排两个班
  → 公式：COUNTIFS(日期=当前日期, 护理员=当前护理员) > 1 时标红

规则2：连续夜班不超过3天
  → 公式：检查前3天是否都是夜班，如果是则标橙

规则3：夜班后至少休息12小时
  → 公式：夜班结束到下一个班次开始间隔 < 12小时 时标红

规则4：每个班次至少2人在岗
  → 公式：COUNTIFS(日期=当前日期, 班次=当前班次, 状态=正常) < 2 时标红

规则5：夜班月度均衡
  → 统计每人本月夜班次数，差距超过3次时提醒
```

### 第3步：飞书日历同步

```
排班表新增/修改记录
  → 自动创建/更新飞书日历事件
  → 事件标题：「白班 - 张三 - A区」
  → 事件时间：对应班次时间
  → 参与人：对应护理员
  → 护理员手机上自动看到自己的班次
```

### 第4步：临时调班流程

```
护理员发起调班请求
  → 飞书审批流：填写调班原因、日期、替班人
  → 主管审批
  → 审批通过 → 自动更新排班表
  → 同步更新飞书日历
  → 推送通知给相关人
```

### 第5步：排班看板

多维表格仪表盘展示：

- 今日在岗人员（按班次、区域分组）
- 本周排班总览（甘特图视图）
- 夜班统计（每人本月夜班次数柱状图）
- 空缺预警（未来7天有空缺的班次高亮）

## 自动化规则

```
触发条件：排班表新增记录
  → 校验排班规则
  → 如有冲突 → 推送提醒给排班人
  → 如无冲突 → 同步到飞书日历

触发条件：每周日 18:00
  → 生成下周排班草稿（基于上周排班 + 规则）
  → 推送给主管确认

触发条件：排班表状态变更为「请假」
  → 检查是否导致该班次人手不足
  → 如不足 → 推送预警给主管
```

## 效果指标

| 指标 | 改造前 | 改造后 |
|------|--------|----------|
| 排班耗时 | 2-3小时/周 | 30分钟/周 |
| 排班冲突率 | 约10% | 0% |
| 夜班分配均衡度 | 差距可达5-6次 | 差距<3次 |
| 调班信息同步 | 口头/微信群 | 日历自动同步 |
